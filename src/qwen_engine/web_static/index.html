    Help

    Backend status
    This page talks only to the local qwen-web server on the same origin, when it is running. Opened over file:// or without that server it is disconnected: planning and authoritative validation are unavailable. Real generation requires explicit server enablement.
    Generation gates
    Unknown until the server answers: adapter, hardware, assets and calibration gates are reported by /api/v1/status. Asset and hardware checks run per job; exact calibration preflight is not wired into generation.
    Generation
    Planning and authoritative config validation come from the local server; generation uses the engine through a serial job queue when enabled by the server operator.
    Runtime paths & model files
    Runtime paths (output, cache, log, benchmarks, models, manifest) belong to the server's own configuration and can never be set from this page; the editable-config export omits them. No model or weight is downloaded by this page.
    Validation of full settings
    What this page checks is a lightweight form check only, not a fitness or memory check. The local server performs the authoritative GenerationConfig validation when it is reachable.
    Privacy
    This page makes no third-party requests and loads no external fonts, scripts or analytics; its only requests are same-origin calls to the local server. The only thing the browser stores is your chosen theme (Original, Neon or Paper), kept under one local key; your prompt, draft and settings are never saved by the browser. Plain static hosting serves these files but enforces nothing by itself — locality is controlled by the qwen-web server's explicit bind addresses. Remote access uses the LAN or Tailscale address selected by the operator.
    Drafts
    Nothing is saved by the browser automatically except the theme choice above. Prompts, seeds and form values are never stored; an opt-in draft store for validated form values may come later.
