`--[no-]tiled-decode` override the preset. 2K selects tiled decode automatically.

## RGBA audit / remaining work

The installed pinned `diffusers/pipelines/qwenimage21/pipeline_qwenimage21.py`
uses `VaeImageProcessor`; its `postprocess` converts tensors to NumPy then
`Image.fromarray` without discarding the fourth channel. Our supplied adapter
requires four decoded channels and the saver accepts RGBA. PNG/lossless WebP
retain alpha; JPEG composites white. This source audit is not a transparent
generation acceptance test. Still needed: explicit original/effective prompt
handling, transparent output controls/format validation, real partial alpha
samples and tiled-edge checks at 1K/2K.

Production memory preflight integration, genre quality review, the other six
2K shapes, official Turbo, single/multiple-reference editing and rewriting
remain unfinished. Do not promote Q8 based on a cube test alone.
