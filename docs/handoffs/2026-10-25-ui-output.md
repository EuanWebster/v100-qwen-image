# Image output and workspace update — 2026-10-25

Implemented after the user's explicit request resumed development:

- JPG is the default output; PNG and lossless WebP are selectable in the UI,
  editable configuration and CLI (`--output-format jpg|png|webp`). JPEG uses
  quality 95 and no chroma subsampling. PNG/WebP preserve available alpha;
  this does not add native transparent generation. JPEG flattens alpha to white.
- Saved and downloaded filenames use `qi21-DDMMYYYY-<actual-seed>.<extension>`.
  The date is local save date. Repeats in the same directory add `-2`, etc.,
  without overwriting. Existing jobs retain their existing names and formats.
- Generate, progress and cancellation are at the top of the form and sticky
  while scrolling, including when Advanced is open.
- Original, Neon and Paper themes. Only the selected theme is stored locally.
- Import editable configuration sits beside Export. Raw file bytes go to
  `/api/v1/config/import`, preserving numeric uint64 seeds before Python parses
  them. Runtime paths and invalid fields are refused. A late import cannot
  overwrite newer draft edits. Import does not start generation.

transformer residency ends before VAE decoding to fit the V100. Avoiding all
reloads needs a separate measured design for CPU model retention and/or Q8 GPU
residency; it is not implemented by this update.
